# Overview design system

Accepted concept: `docs/design/overview-concept.png`

## Visual direction

- Primary surface: true white `#ffffff`.
- Sidebar: charcoal `#181a1d` with selected surface `#292c30`.
- Brand/action accent: Rabbit Bytes orange-red `#f4511e`.
- Borders: cool gray `#dfe2e5`, 1px, almost no shadows.
- Radius: 8–10px for controls and 10–12px for panels.
- Typography: Geist, compact 14px UI rhythm, 30px page title.
- Container model: open app canvas, one sidebar, summary rows and a table—not a bento grid.

## Component inventory

- App shell with desktop sidebar and mobile drawer.
- Six Tabler-icon navigation rows with selected state.
- Required `SANDBOX` environment label.
- Quiet 64px header with user identity.
- Three connection-metadata summaries, all zero in the initial empty state.
- Shop connections table header and a centered empty state.
- Primary Connect Shopee action and setup-guide link.
- Security note that Ads performance is queried live and not stored.

## Copy lock for the Overview first viewport

`Overview`, `Monitor shop connections and open live reports.`, `Connected shops`, `Healthy connections`, `Needs attention`, `Shop connections`, `No Shopee shops connected`, `Connect a Sandbox shop to start querying live Ads data.`, `Connect Shopee`, `View setup guide`, and `Ads performance is queried live from Shopee and is not stored.`

No Ads metrics, sample shops, charts, provider claims, or extra product areas are permitted in the empty-state concept.
